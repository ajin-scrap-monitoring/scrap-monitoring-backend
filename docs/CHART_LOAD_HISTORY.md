# 적재율 이력 그래프용 응답

```http
GET /api/v2/monitoring/load-history?pit_id=pit-demo&view=chart&bucket_seconds=60
```

`view=chart`는 그래프에서 쓰지 않는 긴 근거 식별 문자열을 생략한다. `view`를 생략하거나
`full`로 지정하면 기존 응답을 그대로 반환한다. 기존 조회·집계·표본 선택을 수행한 결과를
변환하므로 그래프용 조회를 위해 DB를 다시 읽거나 별도로 계산하지 않는다.

## 유지하는 정보와 생략하는 정보

응답에는 `view: "chart"`가 추가된다. `schemaVersion`, 피트·출처·요청 기간·구간 길이·선택
정책·표본 수와 순서는 전체 응답과 같다. `samples` 배열과 각 표본의 다음 정보는 유지한다.

- 구간 시작·끝과 실제 생성·관측 시각: `bucketStartAt`, `bucketEndAt`, `generatedAt`, `observedAt`.
- 대표값·유효 여부·품질과 사유: `valuePercent`, `valid`, `dataState`, `reasonCodes`.
- 입력 종류·시뮬레이션 여부·값 선택 정책: `inputSource`, `simulated`, `valuePolicy`.
- 평균·최솟값·최댓값·유효/무효 개수.

`assessmentId`, `observationId`, `methodVersion` 세 필드는 JSON에 포함하지 않는다.
이를 빈 문자열이나 null로 바꾸어 근거가 없다고 표시하지 않는다. 식별자와 계산 방법의
상세 비교가 필요하면 같은 기간·구간 길이로 `view=full`을 조회한다. 두 요청 사이에 데이터가
도착할 수 있으므로 별도 응답이 같은 스냅샷이라고 가정하지 않는다.

0%는 유효한 0%로, 결측·판정 불가 값은 기존 null로 유지한다. 출처 혼합·방법 변경 시의
무효 처리와 사유도 유지한다. 생략한 방법 문자열을 근거로 시뮬레이션이나 품질 표시를
없애지 않는다. 표시용 반올림은 전체 응답과 같고 내부 계산·원본 저장은 바뀌지 않는다.

## 최근 구간 갱신과 과거 구간의 변경 가능성

현재는 **몇 분 이전이면 영구히 고정된다는 기준이 없다.** 지연 도착과 같은 초의 표본
교체로 과거 구간도 달라질 수 있다. `generatedAt`이나 구간 종료 시각은 변경
버전이 아니며, NO_DATA도 추후 데이터가 도착할 수 있다. 이 응답에 불변 시각·변경 커서나
다른 요청과 공유하는 고정 스냅샷을 제공하지 않는다.

기존 `from`/`to`로 최근 범위만 조회할 수 있지만 이것만으로 전체 이력의 정합성을 보장하지
않는다. 과거 변경도 반영해야 하는 화면은 전체 범위를 다시 조회해 결과를 재검증해야 한다.
최근 부분 조회를 병행한다면 다음 기준을 지킨다.

1. 첫 전체 응답의 `bucketSeconds`를 후속 요청의 `bucket_seconds`로 명시한다. 기간이 짧아지면
   자동 해상도가 달라질 수 있으므로 자동 선택 결과끼리 합치지 않는다.
2. UTC epoch 기준의 구간 경계에 `from`을 맞춘다. 분 중간부터 읽은 부분 구간을 전체 분의
   값·평균·표본 수 대신 덮어쓰지 않는다. `to`는 종료 미포함이며 마지막 부분 구간도 바뀐다.
3. 겹치는 구간은 합계를 더하지 않고 해당 구간 전체를 교체한다. null도 이전 정상값으로
   채우지 않는다. 피트·출처·해상도·기간 변경이나 재연결 시에는 전체 범위를 다시 조회한다.
4. 보관 중인 과거 구간도 주기적으로 전체 재조회한다. 최근 몇 분만 고정해 갱신하면서 더
   오래된 구간이 변하지 않는다고 약속하지 않는다.

## 범위와 검증

기간·해상도·최대 표본 수·20초 조회 제한, 세션 인증과 `Cache-Control: no-store`는 기존과 같다.
조회 사용자와 관리자 모두 사용할 수 있고, 잘못된 `view`는 422다. DB 작업량이나 지연을
일정하게 보장하는 옵션은 아니며 JSON 직렬화·전송량과 화면 처리 비용을 줄이는 범위다.
DB 구조·센서 수신·알림·영상 생성은 바꾸지 않는다. 프론트엔드가 새 옵션을 연결해야 적용된다.
