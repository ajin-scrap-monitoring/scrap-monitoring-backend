# 영구 중복 방지와 최소 접수 기록

같은 장치의 같은 메시지 ID·같은 내용은 원래 접수 시각의 중복 ACK를 반환하고,
같은 ID·다른 내용은 충돌로 차단한다. 별도 메시지 ID라도 동일 artifact 식별키의
내용이 달라지면 기존 artifact 충돌 검사를 유지한다. 이 보장에는 기간 제한이 없다.

compact 저장에서 ID·장치·메시지 종류·설정 버전·생성/접수 시각·내용 해시는
`edge_v2_messages` 열에 계속 보존한다. 새 compact 접수 JSON은 열에 없는
`schema_version`, `assessment_type`, `retention`만 보관한다. 원문은 기존 최신
투영·artifact·EVENT 보관 경로를 사용하며, compact가 꺼진 경우의 원문 저장은 바꾸지 않는다.
설정·보정·EVENT 원문·최신 관측·필터·경보·수거·분 이력·수신자·계정·메일은 변경하지 않는다.

## 기존 중복 메타데이터 미리보기

기본은 읽기 전용이며 실제 쓰기는 `--apply`를 명시해야 한다. 자동 작업자는 없다.
DB 접속 정보는 기존 비공개 환경으로 제공하고 명령이나 출력에 쓰지 않는다.

```bash
uv run python -m src.app.cli.receipt_compaction --dry-run --batch-size 100 --max-batches 1
```

`after_id`, `next_after_id`, `scanned`, `eligible`, `changed`,
`serialized_json_bytes_saved`, `exhausted`를 배치별로 출력한다.
`--after-id`로 지정한 ID 다음부터 이어갈 수 있다. 한 배치의 수와 절감량을 전체 DB
대상이나 확보 가능한 디스크 크기로 해석하지 않는다. JSON 직렬화 바이트 차이는 DB 행의
정렬·페이지·인덱스·WAL 비용을 포함하지 않는다.

compact=true, 기존 LATEST_ONLY 접수 형식, 메시지 종류·하위 종류·버전·전체 식별키·
설정·생성 시각이 모두 저장 열과 일치할 때만 중복 필드를 제거한다.
원래 compact JSON의 의미는 나머지 필드와 저장 열로 복원할 수 있다.
추가 필드·잘못된 시각·불일치·원문·EVENT·만료 표시는 수정하지 않는다.

ID로 최대 1,000행까지 먼저 범위를 잡아 원문이 많은 구간도 제한된 범위만 검사한다.
큰 원문을 애플리케이션에 일괄 적재하지 않도록 JSON 길이를 SQL에서 제한한다.
이는 원문 조회 만료나 원문 보관 기간 변경 작업이 아니다.

## 명시적 적용과 재개

대상과 운영 부하를 미리 확인한 뒤, compact 저장이 활성화된 환경에서만 적용한다.

```bash
uv run python -m src.app.cli.receipt_compaction --apply --batch-size 100 --max-batches 1
```

각 배치에서 선택한 행을 잠그고 payload만 갱신하며 성공한 배치만 커밋한다.
실패·취소된 배치는 롤백한다. PostgreSQL에서는 잠긴 행을 건너뛴다. 기존 원문 정리
작업과 같은 행 잠금을 사용하며 잠긴 행은 다음 순회에서 처음부터 다시 확인한다.
`exhausted`는 해당 시점의 ID 검사 범위를 끝냈다는 뜻이며 잠긴 행·새 수신까지
모두 처리했다는 뜻은 아니다. 이미 최소화한 행은 재실행해도 변경하지 않는다.
PostgreSQL 명령 제한 5초·잠금 대기 제한 1초와 배치 사이 대기를 적용한다.

이 도구는 행·고유키·본문 해시·artifact 키/해시·외래 참조를 삭제하거나 옮기지 않는다.
새 스키마나 대형 인덱스 교체·VACUUM FULL·복원은 필요하지 않다. 파일시스템 크기가
즉시 줄어드는 것은 아니며 갱신의 WAL·죽은 튜플 비용이 있으므로 무제한 일괄 실행하지 않는다.

## 운영 정책과 구분

영구 접수 기록과 업무 이력은 계속 증가하므로 전체 DB 고정 크기를 보장하지 않는다.
원문 보관 30일·영상 보관·용량 경고·디스크 확장은 별도 정책이다.
계산 최신성 1초·스캔 경고 3초·최근 5초 중앙값·손실 정상 복귀 1시간·
오류 이력 복구 확인 10초와 화면 표시 유지 기준도 바꾸지 않는다.
