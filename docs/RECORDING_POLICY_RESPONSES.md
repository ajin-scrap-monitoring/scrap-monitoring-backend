# 녹화 정책 저장 응답과 운영 경고

상시·이벤트 정책 PUT은 기존 요청과 공개 응답 필드를 유지한다. 미디어가 PUT 성공 응답에
추가하는 `capacity_validation`은 내부에서 별도로 검증한다. GET과 요청 모델의 엄격한
필드 검증은 유지한다. 이 객체를 다음 PUT 요청에 그대로 보내지 않는다.

미디어의 새 검증 객체가 있으면 `policy_applied=true`를 확인한다. 사전 검증의 false를
저장 성공으로 취급하지 않는다. 이전 미디어의 추가 객체 없는 응답도 지원한다.
설정 저장 성공은 예상 보관 용량의 충분함이나 영상 보관 보장을 뜻하지 않는다.

용량 상태가 `insufficient_capacity` 또는 `unknown`이거나 경고가 있으면 Backend 운영
로그에 `RECORDING_POLICY_CAPACITY`를 기록한다. 로그에는 정책 종류·상태·적용 여부·평가
시각·검증된 경고 코드만 포함한다. 미디어의 임의 메시지·내부 경로·용량 원문은 포함하지
않는다. `estimated_fit`을 장기 무중단 보장으로 기록하지 않는다.

이 로그는 외부 통보 발송이나 도착 확인이 아니다. 정기 감시·통보 수신자·채널·중복 억제·
복귀 통보는 별도 운영 작업이다. Dashboard용 디스크 API·응답 필드·경고 화면을 추가하지
않는다. 운영 보관기간·예산·영상·기존 만료 시각을 자동 변경하지 않는다.
